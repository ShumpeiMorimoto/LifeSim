# デモ（判断用の試作）

設計判断のために作った、**動く試作**の置き場。本番コードではない。ブラウザで直接開ける単体HTMLで、ビルドも依存もない。

作る目的は一つ、**「これで没入できるか」を言葉でなく実物で判断すること**。設計フェーズの議論が机上で止まらないようにするための道具。

## 共通の前提

- **アセットファイル0**（2026-07-27 決定）。画像・フォント・音声ファイルを一切持たず、見た目はCSS/SVG、音はWeb Audio合成で実行時に描く。参考にした実例は [Claude-of-Duty](https://github.com/mshumer/Claude-of-Duty)。
- **演出コストは O(部品数)、O(イベント数) ではない**（CPK方針）。デモはどれも「少数の部品に引数を変えて渡すと別物に見える」ことを示す形にしてある。詳細は `dev-docs/LIFE_SIM_ANALYSIS.md`。

## scene-proto.html — イベントシーンの一枚絵

同窓会（中年期・夜）／放課後の教室（学生期・夕）／病室（中年期・朝）の3場面を、**同じ9個の部品**（人物シルエット・窓・光源・光の帯・家具・小物・粒子・階調・粒状）から組んだもの。1場面あたりの記述は約30行。

テキストの逐次表示、選択肢、ステータス増減の演出、環境音とSE（すべて合成音）まで含む。選択後に緑で出るのは状態モデルへの配線表示（本番では非表示）。

**わかったこと**: コードだけの一枚絵が成立する条件は**顔を描かないこと**。人物をシルエットにして光・空気・構図で語らせれば絵の巧拙が出ず、没入も落ちない。逆に、表情や具体的な描き込みが要る演出は最初から諦める——これが破綻しない線引き。

## portrait-proto.html — NPCのシルエット肖像

上の「顔を描かない」方針をNPCに適用したもの。状態モデルの6スロット（母／父／親友／恋人／ライバル／子）を、髪の輪郭・体格・小物・その人の色だけで見分けさせる。

3つのセクションで構成:

1. **六人を見分けられるか** — 識別子として機能しているかのテスト
2. **関係値が見た目に出るか** — スライダーで関係値を動かすと、縁光・距離・姿勢・彩度、そして**本文そのもの**が変わる。「薄化粧で終わるか、state連動で刺さるか」の分かれ目
3. **同じ人が歳をとる** — 母ひとりをプレイヤーの人生に沿って5枚並べたもの。同じ関数に `age` を渡しただけで、描き分けの手間はゼロ

**論点**: 愛着の本体は状態モデルと本文の側にあり、肖像は「誰の話か」を示すアンカーにすぎない、という仮説の検証。顔がないぶん読み手が想像で埋められる（小説と同じ作りかた）のが利点か、物足りなさか。

**保留中**: ドット絵ポートレートを将来採用する可能性は残っている。状態モデルもstoryletも表現方法を知らないので、この層をそっくり差し替えても手戻りはない。STEP 8 の判断事項。

## hairstyle-kit.html — 髪型キットと、描き込みの段階

「金髪のツインテールに髪飾り、みたいな具体的な見た目は作れるのか」という問いから作ったもの。

- **髪型12種** — ツインテール／ポニーテール／三つ編み／お団子／姫カット／ロングウェーブ／サイドテール／ボブ／ショート／くせ毛／撫でつけ／薄毛。1種あたり15行程度
- **髪飾り6種** — リボン／カチューシャ／ヘアピン／シュシュ／花／なし。**髪型ごとに結び目の座標 `tie` を持たせてある**ので、どの組み合わせでも位置が合う。12×6=72通りを18個の実装でまかなう
- **髪色6種** — 金／黒／茶／亜麻／赤／銀
- **描き込み4段階** — 影だけ／髪に光/髪と肌/顔を描く
- **組み立てUI** — 自由に組み合わせて、storyletから見た指定JSONを確認できる

**わかったこと**: 髪型・髪飾り・髪色は**いくらでも具体的にできる**。技術的な壁はここにはない。壁は**顔**のほうにあって、全身が影なら顔がないのは様式として通るが、髪が金色に光った瞬間「この絵には顔があるはずだ」と目が期待しはじめる。**破綻するのは色の有無ではなく、期待と実物のずれ**。

**トーンの論点（技術とは別）**: 金髪ツインテールが作れることと、この作品に合うかは別問題。現代日本・等身大／シリアス7:ユーモア3の骨格からすると、病室や同窓会の場面では浮きうる。ただし**内輪ネタ枠（6-5）なら逆に特徴が立っているほうが刺さる**ので、「本筋は抑えめ、内輪ネタ枠は自由」という切り分けはありうる。

**要判断**: 本筋NPCを4段階のどれで出すか。これだけが開発者の決めごとで、髪型を何種そろえるかも手描きに移行するかも、あとから足せる/差し替えられるので今決めなくてよい。
