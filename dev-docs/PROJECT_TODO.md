## 恒久メモ（＝再調査するな。確定済みの判断）

- **QBN一択**。「状態ドキュメント＋宣言的条件イベント」は Fallen London の QBN の再発明であり、正しい方向。分岐ツリーは作らない（指数爆発）

- **ライブAI生成は背骨にしない**。検証不能・コスト・トーン制御の喪失・「10,000杯のオートミール」問題。AIはビルド時のみ

- **演出コストは O(部品数)**。1イベント1演出の手作りは禁止。特注 set_piece は「%」でなく**絶対数25**で上限固定
- **トークン節約は常時の要件**。上限に余裕があることは雑に使ってよい理由にならない。割り当ては `LIFE_SIM_DEV_PLAN.md` 付録E
